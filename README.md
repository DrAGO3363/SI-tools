
# SI tools

**SEO Universal — Amir Edition**

SI tools is a desktop application for website SEO auditing and analysis, designed to help website owners and developers identify technical and on-page SEO issues.

## Features

- Website SEO analysis
- Interactive audit dashboard
- Category-based SEO scores
- Audit progress tracking
- Persian and English interface
- Light and dark themes
- Google PageSpeed Insights integration

## Installation

1. Open the **Releases** section.
2. Download `SI-tools-Setup.exe`.
3. Run the installer on Windows.
4. Launch SI tools from your desktop.

**Platform:** Windows 64-bit

**Developer:** Amir.exe

## Notes

An internet connection is required to audit websites. Some external analysis features may require an API key.
