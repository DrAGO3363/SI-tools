How to create a Google PageSpeed API key

  1. Open Google Cloud Console and sign in.
  2. Create a new project or select an existing project.
  3. Go to APIs & Services → Library, search for PageSpeed Insights API, and enable it.
  4. Go to APIs & Services → Credentials and select Create credentials → API key.
  5. Paste the new key into the field above, then run the audit again.
  6. Restrict the key to PageSpeed Insights API and use application restrictions appropriate for local software.

Keep your API key private. Service-account JSON files are not supported. A valid key does not guarantee that Google will allow every request.

📘 راهنمای ساخت کلید Google PageSpeed Insights

  1. به Google Cloud Console بروید و وارد حساب گوگل شوید.
  2. از بالای صفحه یک Project جدید بسازید یا پروژه موجود را انتخاب کنید.
  3. در بخش APIs & Services → Library عبارت PageSpeed Insights API را جست‌وجو و روی Enable کلیک کنید.
  4. در APIs & Services → Credentials گزینه Create credentials → API key را انتخاب کنید.
  5. کلید ایجادشده را کپی کنید و در کادر بالا قرار دهید؛ سپس روی «بررسی مجدد» بزنید.
  6. برای امنیت، در بخش Restrict key دسترسی کلید را فقط به PageSpeed Insights API محدود کنید. محدودیت برنامه را متناسب با اجرای محلی برنامه تنظیم کنید.

🔐 کلید API را عمومی منتشر نکنید. فایل JSON مربوط به Service Account برای این قسمت مناسب نیست. خطای 403 ممکن است حتی با کلید معتبر، به‌دلیل تنظیمات دسترسی یا محدودیت گوگل رخ دهد.
